# G4：统一启动与录屏

2026-10-09 更新：当前 NPU 入口使用俯视、近球连续跟踪与固定球框面积占比 **6%** 停车，目标约一小格距离。完整原理和本次步骤见 [一格距离停车](G4_一格距离停车_20261009.md)。此前实验成绩保留原规则，不能作为新规则已复测的证据。

上一轮 **0.3 m/s、2 倍面积停车阈值**的接近实验已实际运行成功，约 **2.2 秒**触发停车，并完成停止确认（`stop_confirmed=true`）。这是 Mac 仿真身体与 RK3588 板端检测、控制的结果；Claude 计划 4a 要求的窗口录屏需用本次录屏文件验收。

首次切换到统一入口，先在旧终端 **B 按 Ctrl+C**，等板端控制退出；再在旧终端 **A 按 Ctrl+C**，等旧身体退出。

在一个 Mac **启动终端**运行：

```zsh
zsh "/Users/ethan/Documents/RK3588 Microduck/work/run_board_runtime_ball.zsh" --viewer
```

该入口合并原 A/B：后台启动同一无反射橙球场景，前台启动板端控制，SSH 密码仍在这个终端输入。等待 `policy loaded`、`control loop running`，保持启动终端运行；`--viewer` 会打开 MuJoCo 窗口。以后结束统一会话，在这个终端按 **Ctrl+C**，由入口关闭两端。

先将 MuJoCo 窗口摆好，按 Mac **⌘⇧5（Command+Shift+5）**，手动选择录制整个屏幕或窗口所在区域并开始录制。确认已经开始后，在另一个 Mac **实验终端**运行：

```zsh
zsh "/Users/ethan/Documents/RK3588 Microduck/work/run_board_follow_ball_npu_03.zsh"
```

实验入口请求头部俯视，完成站立检查，再以 NPU 检测和 **0.3 m/s** 前进指令接近。前 5 个新鲜球类检测建立目标，此后允许同一目标在 `sports ball/orange` 标签之间延续；球框占整幅画面达到固定 **6%** 即锁定停车，与起始大小无关。该视觉参考在独立静态标定中约对应脚前方 21 厘米，实际停距以本轮画面和记录为准。只需启动、实验两个终端。每次完整复测前须重启启动终端，恢复 HOME 和一次性起步支撑。等实验结束、停止确认与证据回传完成后，用菜单栏的停止录制按钮结束录屏。

任何报错都保留完整输出，在该处停止，不重复启动或重跑控制；若仅证据回传失败，只补传输出指定的本次目录。结束后提供**完整实验输出、相应日志和录屏文件**。我们将核对画面中鸭子是否走向球并停住，以及本次停止记录；是否满足 4a 录屏验收由这些证据决定，不能仅凭开启窗口或此前成功记录宣称完成。
