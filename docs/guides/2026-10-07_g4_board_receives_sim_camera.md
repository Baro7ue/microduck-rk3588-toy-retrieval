## 4. Mac 终端 C：连续完成板端收帧、回传、转成图片

```bash
zsh "/Users/ethan/Documents/RK3588 Microduck/work/probe_board_camera_transport.zsh"
```

这一个命令依次做四件事：

1. 把只读接收程序及复用的接收器复制到板子。
2. 在板子上连接 Mac 的 7901，接收 30 秒画面。每帧先读 4 字节长度，再读完整的 460,800 字节负载，记录到达时间和哈希，保存首末两帧。
3. 将全部证据复制回 Mac。
4. 在 Mac 解码 UYVY，并顺时针旋转 90°，生成两张 PNG。板端只用 Python 标准库，无需安装新依赖。

复制、远程运行、再次复制时可能各要求一次 SSH 密码，正常输入即可。屏幕会显示接收结果、帧数、到达帧率及证据路径。

成功输出应包含 `completed`，且帧数大于零。设置值是 15 fps，实际接收速率以本次数据为准，不因设置值就判定通过。

本协议没有源时间戳或帧号，因此这里测量的是完整帧的到达速率，不能据此报告真实帧龄或唯一新渲染帧率。保持静止时首末图片可能相同。
