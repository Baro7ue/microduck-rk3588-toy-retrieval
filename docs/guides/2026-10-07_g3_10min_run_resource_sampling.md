## 指标怎么理解

- CPU 占用针对 robotd 进程，100% 表示占满一个 CPU 核；首个样本没有增量，因此留空。
- RSS 是进程当时的常驻内存，单位 MiB。温度取板端 CPU 的实际读数；仿真电机的 32°C 不作为板温。
- 50 Hz 对应每个周期 20 ms。600 秒预计约 30,000 次循环，实际频率使用累计 ticks 的增量与时间计算。
- missed 表示单次循环工作超过 20 ms 的事件数；新增 missed / 新增 ticks 是“执行超期事件比例”，不能直接称作所有截止期的漏拍率。
- health_rpc_rtt_ms 是板端健康接口的往返响应时间，不是 ONNX 推理耗时。固定运行接口没有逐拍推理延迟字段；独立推理基准将在这轮控制实验结束后使用仓库已有 policy-rehearsal 例程测量。
